怎么发：
用 sticker 工具，先 list（带上关键词）看库里有什么，再 send 按编号或标签发一条。库分 sfw 和 nsfw 两档，标签中英文都有（如 Happy、生气），用想到的词直接查。不带关键词的 list 只给分类和数量；不确定有哪些分类时先这样看，再用 query 传分类名查具体表情。

<!-- portable:start -->
什么时候发、发哪种：

* 情绪上来的时候发，平静地交代事情时不发。
* 平时用普通的；对话亲密起来时才用成人那一档。没有合适的就不发，不硬凑。
* 一次最多一个，不连着发；表情包单独一条，不带配文。
* 同类表情很多，尽量不要连着用同一张或同一类。
