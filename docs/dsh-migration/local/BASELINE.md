## 本机 AI 补充说明

- 生成命令：`python3 lab/dsh/local/baseline_claude_usage.py --days 30 --out …`，默认 `--match channels`，匹配到的 5 个项目目录正好是 bot1–bot5。
- **覆盖天数只有 1.0–4.4 天，不是 30 天**：每个 bot 只有 1 个当前会话文件 `*.jsonl`，更早的历史在 `*.jsonl.bak*` 备份里（个数和大小见 INVENTORY.md 末尾），脚本不统计备份。每次请求的输入、命中率这类数字样本量够用（每个 bot 111–244 次请求）；"日请求中位数"只基于 1–4 天，参考价值有限。
- 模型一栏：`gemini-3.8-flash-high` 是旧部署经本机 provider-proxy 转接的模型；`<synthetic>` 是 Claude Code 自己写入的占位记录，脚本把它们也算进了请求数（每个 bot 4–7 条）。
- 缓存命中率是 Claude Code 会话文件里记下的数字。经代理转接的模型命中率偏低（8%–12%），可能和代理怎么回报缓存用量有关，本机没有进一步核实。
- bot1 当前没有会话文件（只有备份），所以请求数为 0。
